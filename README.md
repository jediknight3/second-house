# 🏡 세컨하우스 건축노트

세컨하우스 건축의 **비용·공정·사진·업체·미팅·할일**을 한곳에 기록하고 관리하는 웹앱.
단일 HTML(Vanilla JS, 외부 라이브러리 없음) + Google Apps Script/시트 백엔드 — `jayden-finance`와 같은 구조.

## 기능
| 메뉴 | 내용 |
|---|---|
| 🏡 홈 | 입주 D-day, 공정 진행률, 예산 대비 집행, 평당 건축비, 다가오는 일정(미팅·할일·지급예정·공정시작), 최근 사진, 최근 기록 |
| 💰 비용 | 지출 내역(지급완료/지급예정, 분류·업체·공정 연결, 영수증 첨부) · 분류별 예산 대비 집행 · 분석(분류 도넛, 월별, 업체별, 결제수단) |
| 🏗️ 공정 | 기본 13단계 템플릿, 진행률 슬라이더, 일정표(간트), 공정별 사진·지출 |
| 📝 미팅·할일 | 회의록(안건·내용·결정사항·액션아이템), 액션아이템 → 할일 자동 등록, 회의록 복사, 할일 체크리스트 |
| 📷 사진·자료 | 현장사진·도면·계약서·견적서·영수증 업로드(여러 장), 종류/공정 필터, 월별 앨범, 크게 보기 |
| 🤝 업체 | 견적·계약금액, 지급/잔금, 연락처(전화·문자), 관련 지출·미팅·자료 |
| ⚙️ 설정 | 프로젝트 정보, 구글 시트 연결, JSON 백업/복원, 지출 CSV |

## 저장 방식
- 기본: 브라우저 IndexedDB (오프라인에서도 동작)
- 구글 시트 연결 시: 폰·패드·PC 동기화, 사진 원본은 내 구글 드라이브 `세컨하우스_자료` 폴더에 저장 (시트에는 썸네일만)

## 구글 시트 연결
1. 새 구글 시트 → 확장 프로그램 → Apps Script → `Code.gs` 내용 붙여넣기
2. `setup` 함수 1회 실행 → 권한 승인
3. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자)
4. `/exec` URL을 앱 설정에 입력

## 배포
GitHub Pages로 `index.html`을 서비스. (`Code.gs`도 같은 폴더에 두면 설정 화면의 "코드 복사" 버튼이 동작)
